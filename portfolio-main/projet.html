Pizzeria

Le projet ici présent est la représentation d'un site pour un service de commande en ligne. Dans ce site il est possible de commander des pizzas en se connectant avec un compte que l'on crée. Pour la commande, il suffit d'ajouter ce que l'on sélectionne puis d'insérer une adresse afin de pouvoir être livré.

Fleet Manager

Le projet ici présent est la représentation d'une application de gestion de flotte de véhicules. Sur cette application il est possible de louer un véhicule et noter sa consommation de carburant et de voir un graphique sur sa consommation par rapport à la distance parcourue.
